# Decision log

Architecture decision records, one file per decision: `NNNN-short-title.md`, numbered in
order, written from [`../practice/templates/adr.md`](../practice/templates/adr.md). Any
architect proposes one; the decision maker decides. An accepted ADR is never rewritten: a
changed mind is a new ADR that supersedes it.
